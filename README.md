Smart Parking Platform (ParkSpot AI) is a location-based web application connecting urban commuters with private parking space owners to solve city
  traffic congestion and parking scarcity. Built with React 19, Vite, Tailwind CSS, Leaflet maps, and Framer Motion, it monetizes underutilized
  residential driveways and commercial garages near transit hubs, metro stations, and tech parks.

  The platform provides three specialized role-based interfaces:

  • Driver Experience: Real-time interactive GPS map search, vehicle-specific slot filtering (EV, two-wheeler, Sedan, SUV), instant reservations,
  transparent pricing, and digital QR parking passes.
  • Space Owner Portal: List vacant driveways, upload property verification deeds, set custom hourly/daily rates, and monitor rental revenue.
  • Admin Control Center: Review and approve pending property listings, monitor city-wide slot occupancy analytics, and oversee dispute resolutions.

  Featuring an integrated conversational AI chatbot and responsive dark/light modes, SmartParkingPlatform eliminates the average 20-minute search for
  parking, creating a seamless marketplace for smarter urban mobility.
